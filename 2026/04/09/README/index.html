Software Technology Course Blog

This repository contains a static personal blog website created for the course Fundamentals of Software Technology.

The website is built using the Hexo static site generator and deployed through GitHub Pages. It integrates the course assignments and demonstrates the process of building, managing, and publishing a static website using command line tools and Git version control.

Website

The blog is publicly accessible at:

https://Qiyongpeng.github.io

Visitors can browse blog posts and download assignment-related documents from the website.

Technologies Used

The following tools and technologies were used in this project:

  • Node.js – Runtime environment required for Hexo
  • Hexo – Static site generator used to build the blog
  • Git – Version control system used to track project changes
  • GitHub – Repository hosting and collaboration platform
  • GitHub Pages – Website hosting service for static websites
  • Fluid Theme – Hexo theme used to design the blog interface

Project Structure

  • _posts contains the blog articles.
  • files stores downloadable assignment files.
  • public contains the generated static website files.

Assignments Included

Assignment 1 – Command Line & Documentation

The Assignment1 report is included as a blog post and provides downloadable files in both Markdown and PDF formats.

Assignment 2 – Static Personal Blog Website

Assignment2 explains the process of:

  • Setting up the Hexo blog
  • Managing the project using Git
  • Integrating Assignment1 into the website
  • Deploying the website using GitHub Pages
