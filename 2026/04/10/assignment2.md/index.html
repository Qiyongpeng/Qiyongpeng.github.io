Assignment 2 - Static Personal Blog Website

Assignment 2 Report – Static Personal Blog Website

1. Introduction

This project aims to build a static personal blog website using Hexo and deploy it online through GitHub Pages. The purpose of this assignment is to practice command line tools, Git version control, and static website deployment.

Through this project, a functional blog system was created where users can browse posts and download files related to the assignments.

The website is publicly accessible at:

https://Qiyongpeng.github.io

2. Website Setup

The blog was created using the Hexo static site generator. The following steps were taken to set up the website.

Step 1 – Install Node.js

Node.js is required for running Hexo. It was installed from the official Node.js website.

Step 5 – Create Blog Posts

Two posts were created for this assignment:

  • Assignment1 report
  • Assignment2 report

3. Git Version Control

Git was used to manage the development process of the website. All changes were tracked using commits.

Typical commits in the project include:

  • Initialize blog project with Hexo
  • Update blog configuration
  • Adjust theme settings
  • Add Assignment1 report
  • Add downloadable files
  • Update Assignment2 documentation

Using Git allows the development process to be documented and provides version control for the project.

4. Integration of Assignment1

The Assignment1 report was integrated into the website as a blog post.

Users can access the Assignment1 content directly from the website and download the related files.

The following files are available for download:

  • Markdown version of Assignment1
  • PDF version of Assignment1

These files are stored in the source/files directory and linked within the blog post so that visitors can download them easily.

5. Website Deployment

The website was deployed using GitHub Pages. This service allows static websites to be hosted directly from a GitHub repository.

The deployment process involved the following steps:

  1. Create a repository named Qiyongpeng.github.io
  2. Install the Hexo Git deployer plugin
  3. Configure deployment settings in _config.yml
  4. Generate static files
  5. Deploy the website using Git

6. Conclusion

This assignment demonstrates how to build a static website using Hexo and manage the project using Git version control. The blog successfully integrates Assignment1 content and provides downloadable resources.

Through this project, practical experience was gained in:

  • Command line operations
  • Static website generation
  • Git version control
  • Website deployment using GitHub Pages

7. Future Improvements

Although the blog is functional, several improvements could be made in the future, such as:

  • Adding a comment system
  • Improving the website design and UI
  • Adding more blog posts and categories
  • Integrating search and analytics features

These improvements would make the website more interactive and user-friendly.
